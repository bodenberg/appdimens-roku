# Custom scaling strategies (Roku)

`source/AppDimensCustom.brs` ports `appdimens-dynamic` **library-custom**: the same JSON document, text-formula
language, built-ins and presets as Android, iOS, Flutter, React Native, Web, .NET, KMP, Qt, GTK, LVGL, Python and
Games. `tests/source/TestCustom.brs` reproduces the shared 540-case fixture generated by the Kotlin reference engine.

```brightscript
err = AppDimens_LoadStrategies(ReadAsciiFile("pkg:/config/custom-strategies.json"))  ' "" or the error
ad = AppDimens_Custom()                       ' AppDimens() + cdp / csp / cfactor / cresolve
pad = cdp(16, "brand")                        ' global (like cdp(16, s) on the Web); or ad.cdp(16, "brand")
gap = ad.dimen("16cdp-brand")                 ' literal form (like webdimens)
txt = ad.csp(14, "readableText")              ' text, the strategy's font-scale policy applied
hud = ad.cdp(64, "base * pow(sw / 360, 0.8)") ' parsed once, shared per text

AppDimens_CustomFactor("product", function(s)  ' factor from code (s: width, height, sw, density …)
    return s.width / 360.0
end function)
AppDimens_CustomFormula("hud", function(base, s)
    return base * ((s.sw / 360.0) ^ 0.8)
end function)
```

- The screen is the instance's dp space with device class `tv` (desktop/car/watch/vr/phone/tablet from `uiMode`).
  In reference mode `cdp` returns coordinates, like `sdp`.
- Loading is strict and atomic: an invalid document returns the error with its JSON path and registers nothing.
- The registry lives in the BrightScript context: load the document in each component that uses it (keep the
  JSON text in a string field on `m.global` to read it once).
- Lower level: `AppDimens_DecodeStrategies(text)`, `AppDimens_ResolveStrategy(s, screen)`,
  `AppDimens_ScaleResolved(r, base)`, `AppDimens_ScaleSpResolved(r, base)`, `AppDimens_GetStrategy(id)`,
  `AppDimens_SetDefaultStrategy(id)`, `AppDimens_CustomScreen(w, h, density, fontScale, device)`.

Document fields: `extends`, `reference`, `axis` (`smallestWidth|width|height|min|max|diagonal|perimeter`), `curve`
(`linear|power|logarithmic|interpolated|constant|breakpoints|expression`), `multiplier`, `clamp`, `valueClamp`,
`aspectRatio`, `sensitivity`, `fontScale` (`follow|ignore|{max}`), `ignoreMultiWindow`, `formula`, `rules`
(`when: {device, orientation, smallestWidth/width/height/aspectRatio {min,max}, multiWindow}`, `set`).
Built-ins: `scaled power logarithmic interpolated diagonal perimeter fixed`; presets:
`tabletFriendly compactFirst tvSafe wearable gameHud readableText`.
Full reference: [appdimens hub — DOCS/CUSTOM.md](https://github.com/bodenberg/appdimens/blob/main/DOCS/CUSTOM.md).
